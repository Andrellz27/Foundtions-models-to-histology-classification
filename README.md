# Foundtions-models-to-histology-classification
Framework para benchmarking e fine-tuning de Foundation Models em patologia computacional. Foco em classificação histológica ordinal com prevenção estrita de data leakage (split por lâmina de origem) e resiliência a falhas de memória (OOM). Suporta Linear Probing, PEFT (LoRA/BitFit) e Full FT em ambientes de hardware restrito.
